1. Introduction and learning objectives

A phase-locked loop (PLL) is a feedback system that forces the phase (and hence frequency) of an internal voltage-controlled oscillator (VCO) to follow the phase of an input signal. It has three blocks: a phase detector (PD), a low-pass loop filter (LPF) and a VCO.

Operating principle

The PD produces a voltage proportional to the phase difference between input and VCO output. The LPF removes the high-frequency terms and keeps the DC/slow component Vc. Vc retunes the VCO until its frequency equals the input frequency, leaving a constant phase error.

Two ranges every PLL has:
Lock range (hold range) – band of input frequencies around f0 over which a PLL that is already locked stays locked.
Capture range (pull-in range) – band of input frequencies around f0 from which an unlocked PLL can acquire lock. Capture range ≤ lock range, and it depends on the loop-filter bandwidth.

Why it matters

Lock range tells you how far the input may drift before the system loses the signal; capture range tells you how close the input must start for the PLL to find it. Both appear in receiver, clock-recovery and frequency-synthesizer design.

Prerequisites

Op-amp/analog multiplier basics, RC low-pass filter and time constant, VCO concept, feedback and phase, Fourier idea of sum and difference frequencies.

Linear PLL (analog multiplier PD), digital PLL (XOR / edge-triggered PD with analog VCO), all-digital PLL (ADPLL), software PLL. First-order (no filter) and second-order (RC or lag-lead filter) loops.

3. Working principle

Step-by-step operation

  1. Free-running: with no input the VCO runs at f0.
  2. Input applied, outside capture range: the PD output has a beat component at |fin − f0|. The LPF attenuates it so strongly that Vc barely swings and the VCO is not pulled in. The loop stays unlocked.
  3. Input inside capture range: the beat note is slow enough to pass the filter. It frequency-modulates the VCO; the VCO is dragged toward fin and, within a few beat cycles, locks.
  4. Locked: the PD gives a DC voltage that holds the VCO at fin. Vc = (fin − f0)/Ko(Hz/V). The phase error grows as fin moves from f0.
  5. Input drifts further: the phase error reaches ±90° (PD output saturates at its maximum). Beyond that the loop cannot hold the VCO – lock is lost. That edge is the lock range.
Capture is a dynamic (filter-limited) process; lock is a static (DC-gain-limited) property. Hence ΔfC < ΔfL whenever the loop filter has finite bandwidth.

DC vs AC behaviour

DC: sets f0, the PD offset and the lock range through the DC loop gain. AC: the beat-note amplitude at the VCO input is F(jΔω)·Kd…; the filter decides whether the beat can swing the VCO far enough to reach fin.

Assumptions

Linear PD in the range |θe| ≤ π/2; first-order RC loop filter; Ko constant over the range; ΔωC·τ ≫ 1 for the capture approximation.

Advantages, limitations, design considerations

Wide captureNarrow capture
Fast acquisition, but more noise and reference spurs pass the loopBetter noise/jitter rejection, but slower acquisition and risk of missing the signal

Design choice: use a swept VCO or frequency-aided acquisition (frequency detector, charge-pump PFD) when a narrow loop must still acquire from a large offset.

Common misconceptions

  • “Capture and lock range are the same.” – No; capture ≤ lock.
  • “Larger C2 widens the lock range.” – No; it narrows capture only.
  • “Locked means zero phase error.” – No; constant phase error that depends on fin − f0.
  • “Lock range is ±f0.” – No; for the 565 it is ±7.8f0/V.

Interpreting a real Multisim run

  • Locked: input and output show the same frequency, with a fixed phase offset.
  • Unlocked: output frequency stays near f0; Vc shows a beat ripple.
  • Expect hysteresis: the frequency at which lock is lost differs from the frequency at which it is acquired.

5. Equations and derivations

5.1 Free-running frequency (LM565)

f0 = 1.2 / (4 RT CT)   [Hz; RT in Ω, CT in F]

Applies to the 565 VCO with 2 kΩ ≤ RT ≤ 20 kΩ.

5.2 General lock range

ΔωL = ± (π/2) · Kd · Ko · F(0)

Kd in V/rad, Ko in (rad/s)/V, F(0) is the filter DC gain (dimensionless), ΔωL in rad/s. Derivation: in lock, Vc = KdθeF(0) and Δω = KoVc. The PD stays linear up to |θe| = π/2, so the maximum VCO shift is KoKdF(0)·π/2. Physical meaning: lock range grows with DC loop gain and does not depend on filter bandwidth.

5.3 LM565 lock range

ΔfL = ± 7.8 f0 / V   [Hz; V = (+VCC) − (−VEE) in volts]

Empirical datasheet-style relation; larger supply gives a narrower lock range.

5.4 General capture range (derivation)

Let F(s) = 1/(1+sτ). When the input is offset by Δω from the VCO, the PD output contains a beat at Δω which the filter attenuates to |F(jΔω)| ≈ 1/(Δωτ) for Δωτ ≫ 1. The beat swing is therefore reduced and the effective loop gain at that frequency is ΔωL·|F(jΔω)|. For the VCO to be pulled to the input, the swing must at least equal the offset:

ΔωC ≈ ΔωL · |F(jΔωC)| ≈ ΔωL / (ΔωC τ)  ⟹  ΔωC ≈ √(ΔωL / τ)

Valid for ΔωCτ ≫ 1. Limiting cases: τ → 0 (no filter) gives ΔωC → ΔωL; τ → ∞ gives ΔωC → 0. So the capture range can never exceed the lock range.

5.5 LM565 capture range

ΔfC = ± (1/2π) · √[ 2π ΔfL / (3.6×103 · C2) ]   [Hz; ΔfL in Hz, C2 in F]

This is 5.4 with τ = 3.6 kΩ·C2 and Δω = 2πΔf. Note ΔfC ∝ √ΔfL and ΔfC ∝ 1/√C2.

5.6 Inverse form (design)

C2 = ΔfL / (3.6×103 · 2π · ΔfC2)

Decibel conversions and power/efficiency equations do not apply to this topic; the filter attenuation can be written 20·log10|F(jΔω)| dB if needed.

6. Solved numerical problems

Problem 1 (Easy) – Lock range

Given: LM565, f0 = 10 kHz, supply ±6 V. Find: lock range and locking band.
Formula: ΔfL = ±7.8f0/V, V = 6 − (−6) = 12 V.
ΔfL = ±7.8 × 10 000 Hz / 12 = ±6 500 Hz = ±6.5 kHz. Band: 10 − 6.5 = 3.5 kHz to 10 + 6.5 = 16.5 kHz.
Interpretation: once locked, the PLL follows inputs from 3.5 kHz to 16.5 kHz.

Problem 2 (Moderate) – Capture range

Given: same PLL, C2 = 1 µF. Find: ΔfC.
ΔfC = (1/2π)√[2π × 6500 / (3600 × 1×10−6)] = (1/2π)√[40 841 / 0.0036] = (1/2π)√(1.1345×107) = 3 368 / 6.283 ≈ ±536 Hz.
Capture band ≈ 9.464 kHz to 10.536 kHz.
Interpretation: only about 8% of the lock range is capturable – the PLL must start close to f0. Check: ΔωCτ = 3368 × 3.6 ms ≈ 12 ≫ 1, so the approximation is valid.

Problem 3 (GATE-style, Difficult) – Design

Given: RT = 10 kΩ, CT = 0.01 µF, supply ±5 V, required ΔfC = ±300 Hz. Find: f0, ΔfL, and C2.
f0 = 1.2/(4 × 10⁴ × 10⁻⁸) = 1.2/(4×10⁻⁴) = 3 kHz.
V = 10 V, ΔfL = 7.8 × 3000/10 = ±2 340 Hz.
C2 = ΔfL/(3600 × 2π × ΔfC²) = 2340/(3600 × 6.2832 × 9×10⁴) = 2340/2.0358×10⁹ ≈ 1.15 µF.
Interpretation: choose a standard 1 µF or 1.2 µF capacitor; 1 µF gives ΔfC ≈ √(1.149) × 300 ≈ 322 Hz.

Shortcut: ΔfC ∝ √ΔfL/√C2. Quadruple C2 ⇒ halve the capture range; double ΔfL ⇒ ×√2.

8. Core electronics interview preparation

Industry perspective

Real PLLs inside SoCs, RF transceivers and SerDes are charge-pump PLLs with frequency detectors. Designers choose loop bandwidth for the trade-off between lock time, jitter, and spur rejection, and verify acquisition across PVT corners and over-voltage start-up in Cadence/Spectre or Multisim-level models. Validation engineers sweep input frequency up and down to measure the lock/unlock thresholds.

Quick revision notes

  • Beat note → filter → VCO pull-in → lock.
  • Phase error ±90° at the lock edge.
  • Memory aid: Lock = Large, Capture = Cramped.
  • Larger supply V ⇒ smaller lock range.

Advantages / disadvantages of the PLL

+ Selective, noise-tolerant, tracks drifts, no tuned inductors. − Limited acquisition range, can false-lock, filter design sets a trade-off.
